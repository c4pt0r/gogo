`input_esp.c`, `ir_esp.c`, `lcd_st7789.c`, `imu_esp.c`) cite M5Stack's

those projects is copied into this repository.

## Bundled in firmware builds (from ESP-IDF v6.1.1)

The firmware links these from ESP-IDF (<https://github.com/espressif/esp-idf>);
their license files are in the ESP-IDF tree at the paths given.

| Component | License | License file in ESP-IDF |
|---|---|---|
| ESP-IDF (bootloader, drivers, HAL, `esp_*` components) | Apache-2.0, Copyright Espressif Systems (Shanghai) CO LTD | `LICENSE` |
| Wi-Fi and PHY binary libraries (`esp_wifi`, `esp_phy`) | Apache-2.0 (binary distribution), Espressif | `components/esp_wifi/lib/LICENSE`, `components/esp_phy/lib/LICENSE` |
| FreeRTOS kernel | MIT, Copyright Amazon.com, Inc. or its affiliates | `components/freertos/FreeRTOS-Kernel/LICENSE.md` |
| Mbed TLS 4.x (TLS client, crypto, X.509; also linked into the host `gogovm` when built with TLS) | Apache-2.0 (dual Apache-2.0 OR GPL-2.0-or-later; used under Apache-2.0) | `components/mbedtls/mbedtls/LICENSE` |
| CA certificate bundle (`esp_crt_bundle`, trust anchors in flash) | Mozilla CA certificate data via curl's `cacert.pem`, MPL-2.0 | `components/mbedtls/esp_crt_bundle/cacrt_all.pem` |
| picolibc (C library; newlib if the IDF config selects it) | BSD-3-Clause and other permissive licenses | `components/esp_libc/COPYING.picolibc`, `COPYING.NEWLIB` |

lwIP and `esp_netif` are not linked: gogo uses its own network stack
(`runtime/net/`, see `platform/esp32s3/README.md`).
